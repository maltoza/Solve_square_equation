Программа, решающая квадратные уравнения по заданным коэффицентам. 
Перед началом решения есть возможность провести тесты на правильность программы: ручные и случайные. 
Есть возможность ввода коэффицентов через файл, либо через терминал. 
После решения выводит в терминал количество корней уравнения и сами корни.
